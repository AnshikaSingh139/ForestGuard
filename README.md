# 🌿 ForestGuard — Forest Conservation Website

### Protect Nature. Preserve Wildlife. Secure Our Future.

ForestGuard is a forest conservation awareness website built using HTML, CSS, and JavaScript. Its purpose is to educate people about the importance of forests, encourage wildlife protection, spread awareness about deforestation, and promote environmentally sustainable habits.

The website features a nature-inspired design with a green color palette, wildlife imagery, informative cards, and an interactive conservation checklist.

## 🌍 What I Built

I built a responsive website that encourages people to understand the importance of forests and take small steps toward environmental conservation.

### Key Features

* **🌳 Home Section:** An attractive hero section introducing the importance of saving forests.
* **🌱 Why Forests Matter:** Explains the role of forests in maintaining clean air, protecting water resources, supporting biodiversity, and regulating the climate.
* **🪓 Threats to Forests:** Highlights major environmental challenges, including deforestation, forest fires, habitat loss, and pollution.
* **🐅 Wildlife Protection:** Showcases forest wildlife, including tigers, elephants, and birds, and explains their importance to ecosystems.
* **♻️ Interactive Action Checklist:** Allows visitors to select conservation activities they want to follow.
* **📊 Progress Tracker:** Displays the number of completed actions through a dynamic progress bar.
* **🔄 Reset Functionality:** Allows visitors to reset their conservation checklist.
* **📱 Responsive Design:** Adapts the website layout to desktops, tablets, and mobile devices.
* **🧭 Mobile Navigation:** Provides a collapsible navigation menu for smaller screens.

## ⚙️ How to Run the Project

Follow these steps to run ForestGuard on your computer:

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files—`index.html`, `style.css`, and `script.js`—are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, install the Live Server extension in Visual Studio Code and select **Open with Live Server** from the right-click menu.

**Note:** An internet connection is required to load the externally hosted forest and wildlife photographs.

## 🌱 Why I Built This Project

Forests are essential for maintaining ecological balance, supporting wildlife, storing carbon, and sustaining life on Earth. However, deforestation and habitat destruction continue to threaten natural ecosystems.

I built ForestGuard to create a simple and engaging platform that communicates these environmental challenges and encourages people to adopt more sustainable habits.

This project also helped me practise front-end web development and understand how HTML, CSS, and JavaScript work together to create an interactive website.

## 🌎 Environmental Impact

ForestGuard promotes environmental awareness by encouraging visitors to:

* Reduce unnecessary paper consumption.
* Plant native trees and plants.
* Reuse materials and reduce waste.
* Support wildlife conservation.
* Share awareness about deforestation.
* Make responsible and sustainable choices.

The website is an educational awareness project. It does not directly plant trees, collect donations, or verify conservation activities.
